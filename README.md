
# 🎈 Kiddo App

An interactive and educational Android application designed to make learning fun for young children through engaging mini-games, visual recognition, and audio interaction.

[![Download APK](https://img.shields.io/badge/Download-APK-brightgreen)](https://github.com/wadgaonkarrutuja43-bot/Kiddo_App/releases/tag/v1.0.0)
[![Platform](https://img.shields.io/badge/Platform-Android-blue.svg)](https://developer.android.com/)
[![Language](https://img.shields.io/badge/Language-Java-orange.svg)](https://www.java.com/)

---

## ✨ Features

* 🎮 **Interactive Mini-Games:** Engaging activities designed to enhance cognitive skills.
* 🔊 **Dynamic Animal Sounds:** Audio-visual feedback for identifying animals and their sounds.
* 🔷 **Shape & Color Tap:** Fun puzzles helping kids learn shapes, colors, and spatial awareness.
* 🎨 **Kid-Friendly UI:** Bright, intuitive, and simple interface tailored for toddlers and early learners.

---

## 🛠️ Tech Stack & Tools

* **Programming Language:** Java
* **IDE:** Android Studio
* **UI Components:** Android XML Layouts, Material Design Components
* **Build System:** Gradle (Kotlin DSL)

---

## 📱 How to Install

1. Download the latest **`app-debug.apk`** from the [Releases Page](https://github.com/wadgaonkarrutuja43-bot/Kiddo_App/releases/tag/v1.0.0).
2. Open the file on your Android device.
3. Allow installation from unknown sources if prompted by your system settings.
4. Open **Kiddo App** and start playing!
